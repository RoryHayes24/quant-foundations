# Quant Foundations

A long-term quantitative mathematics, probability, scientific computing, and machine learning programme undertaken alongside my Engineering Science degree at the University of Oxford.

## Objectives

- Develop deep probabilistic intuition.
- Build strong scientific Python skills.
- Learn statistical reasoning through theory and simulation.
- Explore optimisation, stochastic processes, and machine learning.
- Build a substantial portfolio of quantitative projects.

This repository documents my progress through the Quant Foundations Programme, including notes, simulations, projects, and reflections.
